# 卒業論文・修士論文発表会 Webサイト

公開URL: https://pcl-sotsushuron.github.io/2026/

- 年度ごとのフォルダ（`2026/` など）に、係の生成ツール（tools/site/build.py）の出力 `output/<年度>/` をそのまま置く
- ルートの `index.html` は最新年度へ転送するだけ。年度が変わったら転送先を書き換える
- 予稿集はここに置かない（GitHub Pages ではパスワード保護が効かないため。Box で配る）
- 管理：組織 pcl-sotsushuron の Owner。係が替わったら新しい係を Owner に足し、前の係を外す
